Start with a tiny language model, trace attention by hand, then teach a model a
response with SFT and LoRA. Every required experiment runs on CPU.

## Choose your lesson

- [Unit 0 · Your first Tiny-LM run](/unit-00) — 45–60 minutes, no ML background required.
- [Attention · From scores to weighted values](/attention) — 90–110 minutes, including an interactive hand calculation.
- [SFT / LoRA · Teach a response, preserve a base](/sft-lora) — trace the response mask and build a low-rank update.

- [Mini-GPT core gate · Code, diagnose, explain](/mini-gpt-gate) — 60–90 minutes, with staged hints and complete reference code.

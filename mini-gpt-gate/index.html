Hints — open only after an attempt

Hint 1: separate the two residual paths

Keep inputs unchanged while computing the normalized attention update. Call attention with mask=allowed; it returns (output, weights). Only the first is added to the residual. The second normalized branch uses the updated hidden state, not the original input. valid broadcasts [B,T,1] across features.

Hint 2: distinguish the two masks

The attention mask determines which keys may contribute before softmax. The loss mask decides which target predictions count in the objective. One cannot replace the other. An attention row of only -inf produces an undefined distribution even when its target is later ignored.

Reference answers — compare after recording your evidence

Reference block implementation
def learner_forward(block, inputs, allowed, valid):
    attended, _ = block.attention(block.norm_attention(inputs), mask=allowed)
    hidden = (inputs + block.dropout(attended)) * valid
    update = block.ffn(block.norm_ffn(hidden))
    return (hidden + block.dropout(update)) * valid

With zero branches, valid output equals input; padded output is zero. GELU and the FFN act on features independently at each time position; masked attention permits information from earlier positions. The model’s distinct block seeds prevent identical initial projection weights while preserving whole-run reproducibility.

Reference diagnosis and explanation
  1. Visible input c with target c rewards copying; use next-token a instead. Fix the dataset to provide tokens[:-1] and tokens[1:] once.
  2. For [1,2,3] versus [1,2,8], a correct decoder has identical first two logits. Restore the causal triangle combined with valid keys. Both safeguards must be disabled to demonstrate the deliberate defect in this implementation.
  3. Sum NLL only for labels != -100, divide by their count. An all-ignored loss is differentiable zero. Give padded queries a safe dummy diagonal before softmax, then zero their outputs so dummy values cannot influence real tokens.

Sampling uses evaluation mode so dropout does not interfere with the local sample seed, then restores each module’s mode. Exact training resume also requires optimizer moments, scheduler/scaler state if present, step/batch position, RNG state, configuration and a data identity check. The norm-ablation differences are 2.389516, 1.105527 and 1.325092; mean 1.606712, sample standard deviation 0.686760. This result describes the fixed toy validation probe. It is not a safety, factuality or broad language benchmark.
